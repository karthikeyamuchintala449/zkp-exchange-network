# Offline Zero-Knowledge Proof Exchange Network

A fully offline system where devices generate and exchange zero-knowledge proofs (ZKPs) instead of raw data, enabling verification of claims like age, identity, or ownership without revealing the underlying information.

## Overview

This system enables privacy-preserving verification without internet connectivity or raw data transmission. Users can prove claims (e.g., "I am over 18") using cryptographic zero-knowledge proofs that can be verified offline.
